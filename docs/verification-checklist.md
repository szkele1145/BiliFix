## 已知背景

- 之前的三次崩溃（17:18 / 17:30 / 17:36）退出码全是 -1，无 Java 堆栈 → 原生层死亡
- 根因：watermedia 强制 D3D11VA 硬解，解码线程拷贝硬解表面回 Java 堆时崩溃
- BiliFix 把 VLC 改为软件解码（`--avcodec-hw none`），代价是视频解码吃一点 CPU，1080p 无压力
